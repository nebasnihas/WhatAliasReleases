SUDO command prefix

Storing your sudo password in the Keychain for the WhatAlias command prefix

Step 1: Store the password

In Terminal, add your sudo password to the Keychain. You will be prompted to type it.

security add-generic-password -a "$USER" -s whatalias-sudo -U -w

Step 2: Confirm it was added

This should print the password you just stored.

security find-generic-password -w -s whatalias-sudo

Step 3: Create the prefix file

Create a file containing this command and set it as the command prefix in WhatAlias.

security find-generic-password -w -s whatalias-sudo | sudo -S -v 2>&1
